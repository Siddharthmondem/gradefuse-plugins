# Gradefuse plugins

The Claude Code plugin marketplace for [Gradefuse](https://www.gradefuse.com).

```
/plugin marketplace add Siddharthmondem/gradefuse-plugins
/plugin install gradefuse@gradefuse-plugins
```

| Plugin                                       | What it does                                                                                                          |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| [`gradefuse`](./plugins/gradefuse/README.md) | The Gradefuse MCP server, plus skills for model-switch decisions, regression triage and pre-merge release-gate checks |

This repository is published from `integrations/claude-code-plugin/` in the
Gradefuse repository; edit it there.
